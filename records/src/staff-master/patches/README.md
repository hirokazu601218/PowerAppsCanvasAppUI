# 差分YAML

> 対象アプリ：共通（自動テスト／ハンドメイド）

v1.11が基準完全版です。v1.12以降、変更が発生したときだけ版別ディレクトリを作成します。未作成のv1.12パッチはありません。

[差分配布方針](../../../../docs/operations/control-diff-policy.md)に従い、変更コントロールの完全なサブツリーと、親・依存・適用順・検証・復元手順を添付します。

Studioのコード貼付は追加操作であり、既存コントロールへ自動マージする機能ではありません。少数のプロパティだけの変更は、対象を明記したPower Fxで更新する方が小さく安全な場合があります。

現在の自動テストアプリは[v1.18適用済み差分](v1.18/INSTALL.md)を参照してください。v1.18-candidateは準備時点の履歴です。
