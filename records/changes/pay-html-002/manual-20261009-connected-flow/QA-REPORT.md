# PAY-HTML-002 接続図改訂の検証記録

- 対象版：0.2-review（2026-10-09）
- 更新基準：`ad433fe322010c5771173a7b7f5857141a9456ed`（PAY-HTML-001レビュー）
- 業務正本の元main：`252abe4aa5d3b1d99a584a30c97d9b48153c91f5`
- 対象：非正本のレビューHTML・共通モデル・ジェネレーター・表示補助・検査。実アプリの実装／公開／実データ処理の結果ではない。

## 改訂内容

1. 15業務を、それぞれ一つの接続図へ改訂。135工程を各1回描き、154業務経路と同一データの工程・経路表を保持した。
2. 作業を角丸、開始・終了をイベント、条件分岐を菱形として描き、役割／実行境界のレーン、合流、差戻し・訂正・再試行の帰還線を接続した。BPMN風レビュー表記であり、BPMN 2.0の実行可能な定義ではない。
3. 画面の方向別詳細経路を12起点・30関係の1:N図へ改訂。認定簿の別タブ起動と利用者の元タブ復帰、人給との利用者によるシステム切替・Excel/CSV受渡し、方式未決の情報受渡しをアプリ内移動と区別した。
4. 図内の横・縦スクロール、幅合わせ、全体表示、100%、拡大縮小を追加。JavaScriptなしでも図・本文・工程・経路表が存在する。

## 正本との整合

- 100操作とその区分、12画面と区分、元の出典一覧は変更していない。WF-01～14の業務定義は同一。
- WF-15のみ、PAY-02／AD-10で確定している通常の新期間適用を図から読み取れるよう、h「新期間への適用を確認」とe→hを共通モデルへ補完した。新しい承認状態・ボタン・制度判定は追加していない。元の遡及／停止経路をすべての改定の必須手順にしないための補完。
- WF-02では候補作成と職員番号発行の並行関係を保ち、給与班の確認・確定を番号発行待ちにしない。WF-04は行別分類と正常行の先行取込を保つ。
- WF-06の提出者と給与班、WF-07の期間終了確定、WF-10の取込不完全隔離について、レーンによって担当・処理責任が逆転しないことを確認した。
- D9以降の計算式、I8、照合キー・出力行対応、同時更新の物理方式、PD-05/06/07/08などの未決境界を維持した。
