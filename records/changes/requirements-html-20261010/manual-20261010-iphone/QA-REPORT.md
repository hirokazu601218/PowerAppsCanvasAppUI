# iPhone閲覧版の修正・検証

利用者がiPhoneのファイルアプリで開き、画面遷移図等が開かないと報告。ファイルアプリのプレビューはPCブラウザーと同一ではなく、JavaScriptによるiframe閲覧と別HTML参照の利用を前提とした案内が不適切だった。利用者端末の具体的なプレビュー挙動は実測していない。

| 工程 | 状態 | 確認内容 |
|---|---|---|
| 1 修正 | PASS | 62関連HTMLを1ファイル化。画面遷移図を冒頭直後に表示。PC入口へiPhone版へのリンクを追加。模擬操作を無効化した閲覧資料 |
| 2 静的検査 | PASS | 生成一致、ID重複0、内部リンク先欠落0、SVG marker等の参照一致、JavaScript／iframe／ローカル外部資産0。28 SVGの図を収録 |
| 2 実描画・クリック | NOT_RUN | ブラウザーのダウンロードがネットワーク側のSite Unavailable応答となり導入できない。iPhone実機／Quick Lookの表示・リンク操作は未検証。静的リンク解決をクリックの実測として扱わない |
| 3 GitHub更新 | PR #136参照 | 同一作業ブランチへ追補。main・公開サイト・権限・業務要件は変更しない |

内部リンクがプレビューで扱えない場合も、関連資料を別ファイルへ開く必要がなく、そのままスクロールして読める。入力・保存等のデモ操作はPC版で確認する。旧失敗・未実施記録を書き換えない。
