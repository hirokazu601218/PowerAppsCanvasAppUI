## 正確な検証上の限界

- 全46ページのモバイル＋無効JavaScriptを一括で検査する試行はタイムアウトした。合格範囲は上記の代表8ページ。全46ページのデスクトップ描画診断と静的検査は別途完了。
- モバイル確認はCSS viewportの実描画であり、実機スマートフォン、Safari、タッチ操作、読み上げ、200%拡大の受入ではない。
- すべての100操作を端から端まで実行したわけではない。処理本体を持たない模擬保存・取込・計算・帳票・外部連携は説明と画面遷移だけを確認した。
- 図の各ラベルの矩形内収まりは全15図で機械確認した。すべての画素・全状態を人が目視したという意味ではない。
- ネットワーク呼出し・外部スクリプト・実ファイル取込・API・実データ更新を行わない実装であることをソースで確認。CUAブラウザの完全なネットワークトレース取得は行っていない。
- 直接のPlaywrightプロセス起動はOS制約で失敗したため、既存クラウドブラウザとローカルHTTPサーバーによるCUAで検証した。DevToolsを利用した診断は未実施。CSS iframeで表示幅を確認。追加ソフトウェアのインストール・公開ホスティングは行っていない。
- 取得したブラウザエラーログには環境の拡張機能のmetadata送信エラーがある。アプリのJavaScriptエラーと区別し、完全なブラウザログ無エラーは主張しない。
