# M_職員基本 Dataverse設計 v0.1

2026-09-16。添付定義書と本Workの確定回答を正本へ反映。対象は隔離テスト環境のみ。

## 確定事項

- 1人1行、最新情報。職員番号は12桁数字文字列、必須・重複不可。
- 税表区分は甲/乙の選択肢、必須。既定値で未入力を隠さない。
- 採用日・退職日は任意。採用日空欄は採用前。
- 在籍状態は日本時間の当日から導出。採用日空欄/未来は採用前、採用済みで退職日空欄/当日以降は在籍、それ以外は退職。
- 住民税登録、5月まで（前年度）、6月、7月以降を除外。対象年度は追加しない。
- 保険4項目は加入/未加入を表す。未確認の空欄と未加入を区別するため、任意のChoiceを使用。
- 勤務時間は所定勤務時間。分単位の整数で保存し、H:mmで表示（7:45=465分）。真偽値や時刻として保存しない。
- 追加費用が発生する設定・セキュリティを弱める変更は事前にユーザーへ確認。それ以外は範囲内で自律的に進める。

## 入力検証と実装上の境界

必須メタデータだけでWeb APIの全書込経路に必須/正規表現制約を保証したとは扱わない。テストデータ投入処理で必須、数字12桁、Choice、日付整合、長さ、非負整数、メール形式を検証。将来の編集/汎用取込は同じ検証とサーバー側検証の要否を設計する。
氏名は姓・名が両方ある場合に全角空白で生成し、氏名単独入力も可。矛盾する氏名を黙って上書きしない。
不明な保険空欄に未加入を既定設定しない。旧サンプルの意味の異なる値は機械置換せず架空fixtureとして明示して作る。

## 在籍状態と検索

採用日空欄の判定を最優先する。日付は日本時間で判定し、アプリを開いたままの日付変更にも対応する。
検索は導出済み全件コレクションを絞るのではなく、採用日/退職日への条件でDataverseへ委任する設計。
税表の表示名と内部Choice値を混同しない。
