# 職員マスタ検索 v1.11 — 導入・操作手順

> 対象アプリ：共通（自動テスト／ハンドメイド）

B案（Fluent 2の業務向け密度＋DADSの案内）と職員検索サイドバー開閉を実装した、**Studio実機確認前の試作候補**です。架空25名と各履歴をYAML内蔵しています。

## 1. 導入

1. 既存アプリを複製／別名保存し、旧画面は確認が終わるまで残します。
2. **新しい空の画面**を作り、任意で`scrStaffMasterSearch_v111`と命名します。
3. 対象環境で`ModernButton@1.0.0`／`ModernTextInput@1.0.0`が利用できることを確認します。実際に挿入した部品の版が異なる場合は、部品コードとエラーを共有してください。
4. 認定簿PDFの式を含むため、設定→今後の機能（Upcoming features）→実験的（Experimental）→PDF functionをオンにします。PDFは実験的機能です。[Microsoft：PDF function](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/how-to/pdf-function)
5. [貼り付け用YAML](../../../other/src/staff-master/scrStaffMasterSearch_v1.11.paste.yaml)をテキストエディターで開いて全文コピーし、ツリービューで**画面そのもの**を選んで貼ります。数式バー、読み取り専用コード表示、コンテナへは貼りません。コード貼付は新規部品作成です。[Microsoft：code view](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/code-view)
6. 画面直下に`conStaffMaster111`と`pdfLedger111`が並ぶことを確認します。PDFViewerをコンテナ内へ移すとPA2131の原因になります。
7. App.Formulas、App.OnStart、Screen.OnVisibleへ追加するデータ読込式はありません。初期化操作なしで25名と山田 太郎の詳細を表示する構成です。
8. **F5／プレビュー**で操作します。編集状態の通常クリックは部品選択であり、ボタン動作の確認にはなりません。

[管理者用画面定義YAML](../../../other/src/staff-master/scrStaffMasterSearch_v1.11.pa.yaml)は`Screens:`を含む管理版で、Childrenは貼付用と同じです。**2種類を両方貼る必要はありません。**

表示基準は1366×768／1920×1080、外側余白16pxです。画面が実行領域に追従する設定で確認し、編集キャンバスの縮小倍率だけで文字サイズを判断しないでください。小画面・スマートフォン完全対応は今回の完成範囲ではありません。

| 00990000003で検索 | 佐藤 一郎の1名 |
| 組織01秘書課／状態退職 | それぞれ9名／3名。条件はAND |

| 次へ／前へ | 20名／5名のページ切替 |

| 左上の‹ | 検索欄を360px→48pxへ折りたたみ、右詳細を328px広げる |
| 左端の› | 条件・結果・選択・ページを保って再展開。検索は再実行しない |

サイドバーは**手動開閉**です。職員選択だけで自動的には閉じません。閉じても右側の氏名・番号・所属は残ります。開く／閉じるは44×44pxの同一ボタンで、Tooltipと読み上げ名も切り替えます。

## 3. デザイン・部品

- 本文10.5pt（14px相当）／大文字12pt（16px相当）を起点とします。見出しSemibold、本文Normal。実表示倍率・日本語フォールバックの実機校正は未実施です。
- 左一覧は氏名・状態／番号・所属の2段表示。基本9項目、全履歴群、サンプル給与詳細15項目、帳票69フィールドを維持しています。
- ボタン22個と検索入力をモダン化。3つのドロップダウン、透明行選択ボタン、表Label、手動コピー欄は互換性上の例外です。
- 右の職員サマリーを固定表示し、詳細は縦スクロール。横長表は横スクロールし、列を極小化しません。
- 初期化不要の埋込テーブル方式と帳票画像を維持するため、完全版YAMLは大きめです。v1.12以降の通常配布ではこれらを毎回再掲しません。

## 4. PDF・出力の注意

認定簿PDFは専用領域から生成し、Screen直下のViewerへ渡す既存方式を維持しています。有効化だけで保存フローは作成されません。

ファイル保存が必要な場合は、Power Apps (V2)の`file`入力と`fileurl`応答を持つ`SaveCommuteLedgerPdf`フローをアプリへ追加し、[保存用Power Fx](../../../other/src/staff-master/CommuteLedger_v1.11_SavePDF_OnTimerEnd.fx)を**`tmrLedgerPdf111.OnTimerEnd`**へ設定します。App.Formulasへは貼りません。実フローの引数定義が異なる場合は接続契約を先に確認します。

未接続時に保存成功を装う処理はありません。正式用紙・2ページ改ページ・保存先権限・出力内容は実機確認が必要です。認定簿の経路・月額10,480円は共通サンプルで、通勤支給予定の金額や認定IDとは未整合です。

検索・給与項目の出力はTSVコピーであり、XLSXファイルの自動生成ではありません。Excelへ貼る際は先頭0のある職員番号を文字列として扱ってください。簡易印刷は表示中の5行のページのみで、認定簿PDFとは別機能です。
