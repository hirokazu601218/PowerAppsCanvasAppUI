## 判明した問題
1. Studio貼付後、ルートHeightとスクロール領域Yが数値に置換された。貼付後の全プロパティ読戻しが必要。
2. Monaco数式エディターへの `fill()` は置換として使えない。最終読戻しで `truefalse`、`Parent.Height-Self.Y754` 等の連結を検出。プロパティ更新はクリック→Meta+a→クリップボード貼付→別コントロール選択→読戻し完全一致を必須にする。この方式でOnVisibleの初期設定は成功していた。
3. ギャラリーに `As row` を指定したため、行見出しは `row.Label` を使う。候補ソースは修正済み。最終画面全体のApp checker合格は未取得。
4. 日付選択の上限9999年は選択肢が多い。年月専用入力への変更も含め操作性・軽量性を再検討する。業務上の年を固定しない。
5. 長文セルの全文到達、幅の狭い画面、再取得の全契機、データ取得上限の検知が未完成。
6. 編集用の正式HTMLは隔離テーブルGUIDと参照先を一致させる必要がある。元HTMLへ編集用GUIDを渡さない。
