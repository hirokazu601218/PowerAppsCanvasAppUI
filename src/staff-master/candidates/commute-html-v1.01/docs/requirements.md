# HTML帳票追加機能の要件と受入ID

ユーザーの今回承認を根拠とする追加要件。既存帳票機能を置換せず、以下のIDで追加試験を区別する。

| ID | 要件・合格条件 | 現状 |
|---|---|---|
| RPT-HTML-01 | 採用様式の全欄をA4横2ページ・1PDFへ収め、日本語と罫線が欠けない | ローカル組版は合格。Edge印刷は未確認 |
| RPT-HTML-02 | 選択認定のGUIDのみを新タブへ渡し、認定・職員を読取り、値が一致する | 実装・モック試験合格。実環境照合は未確認 |
| RPT-HTML-03 | 利用者のDataverse権限を適用。権限なしや不一致で別人・旧データを表示しない | アプリ選択チェック・模擬エラー試験合格。実権限試験は未確認 |
| RPT-HTML-04 | 空欄・0を区別し、長文を黙って省略せず、はみ出しでは印刷停止 | 単体・ローカル検出は合格。最大長での正常印刷は未対応、Issue #68 |
| RPT-HTML-05 | 既存PoC・他Workの定義・データを保持し、追加差分だけ公開する | ヘッダー差分比較・保存読戻し・対象公開を確認 |
| RPT-HTML-06 | 設計・ソース・試験・未確認・利用手順・復旧手順をGitHubに記録 | 本ディレクトリとSTATUS、Issue #68 |

公開はユーザー承認済み。公開成功と業務受入を区別し、RPT-HTML-01〜03の実環境試験後に本番利用可否を判断する。
