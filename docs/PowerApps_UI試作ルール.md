# 非常勤給与プロジェクト PowerApps UI試作ルール

## 1. 目的

本ルールは、非常勤給与プロジェクトの「PowerApps UI試作」Workにおける成果物の作成形式を統一することを目的とする。

## 2. 適用範囲

本ルールは、このWorkでChatGPTが作成するPower AppsキャンバスアプリのUI試作に適用する。

## 3. UI試作の作成形式

1. キャンバスアプリのUIは、Power Appsへ貼り付けて使用できる **YAML＋Power Fx** で作成する。
2. UI実装用のソースとして、YAML＋Power Fx以外の言語は使用しない。
3. 作成するコードは、Power Apps Studioのコード表示・貼り付け機能で利用できる形式を前提とする。
4. UIは画面単位またはルートコンテナ単位で作成・修正し、可能な限り既にPower Appsで動作確認できたYAMLを基に反復する。

## 4. 例外

1. ユーザーが、このChatGPT上でUIのイメージ、モックアップまたは画像の作成を明示的に指示した場合に限り、HTMLまたは画像を作成してよい。
2. ユーザーから明示的な指示がない限り、HTML、JavaScript、CSS、Reactその他の言語・形式によるUI試作は行わない。
3. HTMLまたは画像で作成したイメージは、Power Appsへそのまま貼り付ける実装ソースとは扱わない。

## 5. 成果物の格納

作成した資料およびソースは、「非常勤給与プロジェクト ファイル格納ルール」に従い、ライブラリの「非常勤給与」フォルダ配下にある「PowerApps_UI試作」フォルダへ格納する。

## 6. ルールの優先順位

このWorkでUI試作を行う場合、本ルールを標準の作成方針とする。ユーザーが個別の依頼で異なる形式を明示した場合は、その依頼に限ってユーザーの指示を優先する。
