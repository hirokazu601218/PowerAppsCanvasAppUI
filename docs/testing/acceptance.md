## 実行

Python 3.10以上、PyYAMLを用意し `python tests/validate_v108.py` を実行する。検査はv1.08固定の回帰試験。新しい版では対象名を更新し、旧版から変わった期待値を説明する。
v1.08の検査器は限定的Power Fx評価器であり全関数を評価できない。未対応関数を合格扱いで無視しない。
