## サイドバー個別確認

- 1366×768と1920×1080で展開／折りたたみを5回繰り返し、空白列、重なり、横切れ、幅の累積誤差がない。
- 折りたたみ中、検索入力・所属・状態・職員一覧へTabフォーカスが入らず、開くボタンはキーボードで操作できる。
- 「山田」で検索し2件目を選択、ページを移動できる条件でも、閉じる→開く後に条件・結果・選択職員・ページ番号が一致する。
- 職員行の選択だけではサイドバーが閉じない。認定簿モーダル表示中は背面の開閉操作が効かない。
- 標準文字と大きな文字で、開く／閉じるの表示またはTooltipが欠けず、現在の状態を色だけに依存せず判別できる。

## 実行

Python 3.10以上、PyYAMLを用意し `python tests/validate_v111.py` を実行する。基準版の回帰確認は`python tests/validate_v108.py`。v1.11では検索・帳票の回帰に加え、8組の寸法モデル、開閉の状態保持、標準／大文字、全表示フィールド保持を検査する。
この検査器は限定的Power Fx評価器であり、公式の型検査や全関数の実行はできない。未対応関数を合格扱いで無視しない。

配置モデルの描画はPillowと日本語フォントを用意して`python tests/render_v111_model.py --font <Regular.ttf> --bold <Semibold.ttf> --out <出力先>`を実行する。実YAMLの式を評価した近似画像で、Fluentネイティブ描画・スクロール・アクセシビリティの実機証跡ではない。フォント配布元のライセンスを確認し、フォント・一時画像をソースへ混在させない。
