## 具体的な提案

現行v1.26を対象とする別の実行プロファイルを追加し、旧v1.11仕様を保持する。現行の12桁番号・5履歴・既存独立fixtureを明示し、D2は日額ではなく給与調整額、0、空、50反復備考を持つ専用fixtureとして定義する。導入・差分・復元は現行の基準ソースを固定し、既存6画面を保つ複製アプリ上で試験する。同一アプリ別画面というDEP-03を別アプリ比較へ変更する場合は仕様変更として明示し、従来条件の合格とは扱わない。

基準の変更を黙って行わず、旧仕様維持か現行プロファイル追加かを確定してから残件の合否を判定する。

人によるVIS-06/ACC-06/OPS-02、VIS-05の画像承認は引き続き人の記録が必要。既知不具合は記録のみ、修正許可は不要・要求しない。
