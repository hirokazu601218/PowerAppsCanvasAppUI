## 原本と構成

デジタル庁公式 https://www.digital.go.jp/resources/standard_guidelines のDS-120「各種テンプレート」2026年7月15日掲載ZIP中 `５章/要件定義書標準テンプレート.docx` を確認。3章、31節、106小項目、計140見出しを原本順に保持します。番号はHTML上の参照用に階層付番しています。記載要領・記載例の文章や挿絵をそのまま契約要件に移すものではありません。テンプレートSHA-256と取得URLはJSONに記録。

- `requirements-data.json`：章番号、原本見出し、要件本文、未設定条件、状態、根拠パス。出典SHA-256を保持。
- `index.html`：静的本文＋検索／未設定抽出＋関連資料閲覧枠。JavaScriptなしでも本文・リンクを利用可能。
- `sources/`：根拠MarkdownのHTML閲覧版。元の状態・旧記述も保持し、新しい確定事項が優先する旨を表示。Mermaidは原文コードで表示し、描画済み業務・画面図へは入口から進む。
- `../../review/pay-html-001/`：既存の画面・業務レビュー。複製や仕様変更は行わない。

元main：`252abe4aa5d3b1d99a584a30c97d9b48153c91f5`。既存レビュー先頭：`c1008452348fd27448742796069647584278dca6`。給与2026-10-07確定要件、人給2026-10-08決定を優先。画面の存在、確定改修要件、提案、未決、未実装・未検証を区別します。D9以降の式は保留を維持。

## 利用

ブランチをダウンロード・展開して `index.html` をブラウザーで開いてください。画面関連HTMLを含むフォルダー構造を保持します。GitHubのblob表示はHTMLの実行プレビューではありません。外部CDNやネットワークで資料を取得しません。根拠HTMLからの未同梱資料参照と公式資料／GitHub原文リンクのみネットワーク接続が必要です。スマホでは関連資料の「別タブで開く」も利用できます。

## 更新

1. Markdown正本・優先順位・未決を読み、JSONの該当要件・根拠・出典ハッシュを更新。
2. `node scripts/review/generate_requirements_html.mjs` を実行。Nodeのmarkedが必要。実行環境では `CODEX_PRIMARY_RUNTIME_NODE_MODULES` を利用。別環境ではmarkedを解決できるNode環境を用意。
3. `node scripts/review/generate_requirements_html.mjs --check` で生成一致を確認。
4. 相対リンク・表示・検索・未設定抽出・閲覧枠・閉じる・JavaScript無効を確認し、結果はrecordsへ記録。

元Wordは再配布しません。今回のHTMLは新しい制度判断、承認済み仕様、アプリの実装・受入合格を追加しません。

## iPhoneのファイルアプリで開く場合（2026-10-10追補）

[iPhone閲覧版](index-mobile.html)を開く。62資料を1ファイルに同梱し、JavaScript・iframe・別ファイルの読込みを使用しない。図・表・画面構成は元の資料から収録し、模擬入力／保存ボタンは無効化する。画面遷移図は冒頭の案内直後に表示。内部リンクは同じファイル内の位置へ移動し、プレビューがリンクを処理しない場合もスクロールで閲覧可能。原本や非同梱資料への外部リンクだけはネットワークが必要。

「ファイル」アプリのHTMLプレビューではPC版のJavaScript閲覧枠・別HTML参照を利用できない場合がある。これをPCと同じ動作として案内していた点を訂正する。iPhone実機でのリンク挙動・実描画は未検証であり、同一HTMLの構造・参照・依存除去を検証済み。

再生成は `python scripts/review/package_requirements_mobile.py`、生成一致の確認は同じコマンドに `--check` を付ける。Pythonのlxmlが必要。
