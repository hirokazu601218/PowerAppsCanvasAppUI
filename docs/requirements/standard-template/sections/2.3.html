2.3 帳票に関する事項

この章・節に含まれる項目

  • 2.3.1 帳票一覧

    通勤手当認定簿は別タブHTML・ブラウザー印刷によるA4横2ページ。人給連携のxlsx出力は外部インタフェースとして管理する。

    一部設定・要件未設定あり

  • 2.3.2 帳票イメージ

    既存通勤帳票は公式様式による2ページ構成。今回の資料は帳票原本を変更せず、詳細設計・通勤帳票レビューへの参照を設ける。

    一部設定・要件未設定あり
標準テンプレートの補助項目・記入要領 案件の要件とは別

次は公式テンプレートが記入を促す項目です。例文・例示値・推奨条件を、そのまま本アプリの確定要件にしていません。

原本の記入ガイド

  • 帳票イメージのサンプルはデジタル・ガバメント推進標準ガイドライン実践ガイドブック「第3編第5章Step.5.1.C.帳票に関する事項 図 5-6帳票イメージの定義例」を参照してください。
  • ペーパーレス化推進のため、開発事業者からペーパーレス化の提案を受けることも一案です。 事業者からペーパーレス推進に向けた提案を受け付ける場合の文言例：「現時点での想定している帳票を記載しているが、必ずしもこれらの帳票を全て本システムで実装する必要はなく、業務効率化やペーパーレス推進の観点から既存の帳票を見直すことも可能である。必要に応じてペーパーレス推進のための提案を行うこと。」
