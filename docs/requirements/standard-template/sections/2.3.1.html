現在の要件

通勤手当認定簿は別タブHTML・ブラウザー印刷によるA4横2ページ。人給連携のxlsx出力は外部インタフェースとして管理する。

要件未設定・判断が必要な内容

その他帳票の正式一覧、出力権限・配布条件の残る詳細。

具体的な条件・対象範囲・判定基準を未設定のまま表示しています。レイアウト案やテンプレートの例から補いません。

関連する既存操作モデルの具体内容です。下位仕様や画面配置が提案の場合は、その区分を維持しています。

項番 / 帳票ID / 帳票概要 / 入出力形式 / 該当機能 / 補足

表内の見本値は本アプリの要件へ採用していません。

原本の記入ガイド

  • 各項目には以下の内容を記載します。 帳票ID：帳票を一意に識別するためのID 帳票概要：帳票の用途、出力場所等 入出力形式：帳票を入出力する形式（出力帳票がPDF形式の場合はデータ集計できない等のデメリットがあるため、利用者に配慮した形式を検討してください。） 該当機能：当該帳票と紐付く機能ID
  • 帳票一覧には必要に応じて以下の項目も加えることができます。 帳票名：帳票の内容を表す名称 入出力の区分：入力帳票、出力帳票等 帳票入出力要件：入力方法（ＯＣＲ等）及び出力方法（モノクロ印刷、カラー印刷、事前印刷用紙（プレプリント用紙）使用、ラベル印刷等）等 帳票設計要件：帳票設計に求める要件 利用者区分：当該帳票を利用する利用者区分
  • 可能な限り各帳票に対して業務や機能との紐づけが分かるように記入してください。
