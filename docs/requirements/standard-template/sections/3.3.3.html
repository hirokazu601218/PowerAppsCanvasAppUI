現在の要件

人給連携の規模は、通常約800レコードを想定する。

要件未設定・判断が必要な内容

件数上限・処理時間基準、システム全体／月間の件数、ピーク、総容量・増加率。約800を利用者数・上限・性能合格値には読み替えない。
