現在の要件

画面・外部境界

  • SCR-001 ログイン画面＆ホーム画面

    現行4主ボタンから業務画面へ移動。外部Microsoft認証をCanvas内画面とみなさない。

    現行実装 ログイン利用者

  • SCR-002 職員マスタ検索・詳細

    検索・履歴・6タブ表示の現行画面。E・F・Gの将来業務を既存タブに追加する。

    現行実装 会計課給与班 / 局担当者

  • SCR-005 支給明細画面

    選択職員・対象月の内蔵仮例による支給内訳試算。給与班の本番計算・確定と分ける。

    現行実装 会計課給与班 / 局担当者

  • FUT-JLINK 人給連携

    支給回ごとに出力・給与簿取込・最新照合・給与班確定を行う承認済み構成。

    確定改修要件 会計課給与班

  • EXT-JINKYU 人給システム（外部）

    職員がExcelを取り込み、人給で必要な処理を行い給与簿CSVを出力する外部境界。

    確定改修要件 会計課給与班

関係の種類を区別する

  • アプリ内: ホームから各業務画面へ。支給明細は職員詳細から開きます。
  • 通勤認定簿: 別タブで表示し、元の職員詳細タブへ戻ります。
  • 人給: 利用者が別システムへ切り替え、Excel・CSVを受け渡します。自動の画面遷移ではありません。
