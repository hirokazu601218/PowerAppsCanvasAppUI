DS-120 / 原本 2.1

2.1 機能に関する事項

この章・節に含まれる項目

  • 2.1.1 機能一覧

    PAYREQ-01～10で全体構造、職員、勤務条件、保険税控除、通勤、勤怠、計算確定、人給照合・追給返納、役割、構築保存検証を追跡する。現行R15～R23と将来FR-*を区別する。

    記載済み

  • 2.1.2 技術検証

    隔離データで既存画面・帳票・勤怠等の検証を行う。HTMLの模擬操作は業務処理の実装・受入証拠にはしない。

    一部設定・要件未設定あり

  • 2.1.3 機能の主な追加・変更点

    勤怠再取込は職員行の追加更新・未掲載行保持・手修正上書き・空欄消去へ改修する。現行全置換と区別する。人給連携は同一画面3タブとし、最新版計算結果との照合を行う。

    記載済み

  • 2.1.4 今後の機能追加を踏まえた構成

    本人機能は初回対象外とし、将来追加できる構造とする。履歴と計算根拠を保持する。

    一部設定・要件未設定あり

  • 2.1.5 機能構成概念図

    画面・業務・操作の関係は既存レビューHTMLの全体遷移図と業務別フローを参照する。システム構成は基本設計に記載。

    記載済み
