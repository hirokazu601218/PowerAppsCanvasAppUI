3.3 システム規模に関する事項

この章・節に含まれる項目

  • 3.3.1 規模に関する前提条件

    人給連携の規模は、通常約800レコードを想定する。

    一部設定・要件未設定あり

  • 3.3.2 データ量

    人給連携の規模は、通常約800レコードを想定する。人給出力は237列（A〜IC）である。

    一部設定・要件未設定あり

  • 3.3.3 処理件数

    人給連携の規模は、通常約800レコードを想定する。

    一部設定・要件未設定あり

  • 3.3.4 利用者数

    要件未設定

  • 3.3.5 保管データ量・保管期間

    処理中は各計算版と根拠を保持する。差分ゼロで支払い確定後は中間版・中間根拠を削除可能とするが、最終結果、最終版の勤務条件・勤怠・単価等の計算根拠、給与簿、支払実績は残す。照合処理回ごとの日時・実行者・件数・状態、不一致職員・項目・双方金額・差額を、中間版削除後も参照できるよう保持する。Excel／CSVファイル自体の継続保存は不要。

    一部設定・要件未設定あり
