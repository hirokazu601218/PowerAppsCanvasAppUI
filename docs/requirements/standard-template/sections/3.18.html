3.18 保守に関する事項

この章・節に含まれる項目

  • 3.18.1 保守業務の実施

    改修時は版管理と試験選定を適用する。変更した部品・数式の単体試験は必須とし、他部品・画面・データ・帳票・外部連携に影響する場合は結合試験も選定し、記録と実測を残す。

    一部設定・要件未設定あり

  • 3.18.2 保守設計

    要件未設定

  • 3.18.3 アプリケーションの保守

    アプリの改修は影響分析とケース選定に基づき、変更部品の単体試験および影響先の結合試験を実施する。公開版とGitHub候補ソースの同一性を別に確認し、未実施・未照合を合格にしない。

    一部設定・要件未設定あり

  • 3.18.4 クラウドサービスの保守

    要件未設定

  • 3.18.5 ソフトウェア保守

    要件未設定

  • 3.18.6 保守実績の評価及び改善

    要件未設定

  • 3.18.7 ドキュメントの保守

    要件→設計→試験をIDで追跡し、変更時に関連資料と未決一覧を更新する。

    一部設定・要件未設定あり

  • 3.18.8 軽微な改修

    要件未設定

原本の記入ガイド

  • 他の事業者が保守を行う場合は、以下を参考に記載してください。 記載例：情報システムの保守の作業内容は以下のとおり。なお、サービスレベルで規定された時間以内に、対応を開始できる体制下で実施されることを要件としている。また、以下の保守要件は現時点のものであり、保守設計において具体的な作業等を確定の上で本システムの運用・保守事業者の調達を行う予定である。
