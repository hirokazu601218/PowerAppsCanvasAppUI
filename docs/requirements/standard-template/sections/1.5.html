現在の要件

給与簿との項目・合計差額、欠落・余分・重複を確認し、差分がある間は給与班確定を不可とする。返納の回収済額・残額を管理する。

要件未設定・判断が必要な内容

処理時間・生産性等の業務KPI、測定頻度、評価責任者。

具体的な条件・対象範囲・判定基準を未設定のまま表示しています。レイアウト案やテンプレートの例から補いません。

操作条件まで確認する

関連する既存操作モデルの具体内容です。下位仕様や画面配置が提案の場合は、その区分を維持しています。

給与班が支給回を確定

確定改修要件

給与班が確定ボタンで確定する。確認ダイアログは出さない。ゼロだけで自動確定しない。

担当: 会計課給与班

項番 / 指標の種類 / 指標名 / 計算式 / 単位 / 目標値 / 計測方法 / 計測周期

表内の見本値は本アプリの要件へ採用していません。

原本の記入ガイド

  • 管理すべき指標には定量的に測定・評価できる指標を記載します。
  • デジタル・ガバメント推進標準ガイドライン実践ガイドブック「第３編第９章Step.2.2.B.指標の基礎データを誰がどのように集めるかを明確にする」の「参考 9-2主な指標とデータの関係例」に例示があります。
  • 各項目には以下の内容を記載します。 指標の種類：業務の運営上管理すべき指標の種類 指標名：指標の種類に属する指標名 計算式：指標の計算式 単位：指標の単位 目標値：目的の達成を評価するための、時期と指標値 計測方法：指標を評価するための計測方法 計測周期：計測を行う頻度
  • データの取りこぼしが発生しないよう、収集方法だけでなく計測周期まで明確にしておく必要があります。
