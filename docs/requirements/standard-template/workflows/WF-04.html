    専用画面。現行PoCとは別。

  2. Excelを選び行検証

  3. 不備・重複候補があるか

    人の存在だけで一律禁止しない。内容を比較。

    FUT-IMPORT
  4. 正常行を先に取込

    問題のない行は先行反映可能。

    FUT-IMPORT / OP-IMPORT-APPLY
  5. 問題行を給与班が判断

    取込済み・重複可能性等の注意を確認。

    FUT-IMPORT / OP-IMPORT-APPLY
  6. 確認待ち候補を作成

    行別の処理結果を保持。

    FUT-IMPORT / OP-IMPORT-APPLY
  7. その行の取込を見送る

    問題行だけ見送り。再取込手順は未決。

    FUT-IMPORT
