E 条件・控除の確認と訂正

実際の変更と誤登録訂正を分け、同じ確認待ちへ合流。不足は訂正へ戻し、給与班確定後に未払い分へ反映します。

流れと戻り・分岐

青の実線: 業務の順序。茶色: 訂正・再試行。破線: 外部システムとの受渡し等。内部画面移動、別タブ、利用者による人給への切替を混同しません。

何を入力・確認するか

  1. 登録・変更・訂正が必要

    基本は最新値、給与条件・所属・控除は期間履歴。

    SCR-002
  2. 実際変更か誤登録か

    月途中の実際変更と誤りの訂正を分ける。

    SCR-002
  3. 新しい有効期間履歴

    勤務条件に発令を統合。保険資格日と控除期間を分ける。

    SCR-002 / OP-E-HISTORY
  4. 前後値を残して訂正

    確定済み履歴も誤登録訂正可。再確認まで計算に反映しない。

    SCR-002 / OP-E-CORRECT
  5. 確認待ちに提出

    保険未確認と非加入を区別。

    SCR-002 / OP-E-SUBMIT
  6. 給与班が内容を確認

    必要条件の未確定は支給確定不可。

    SCR-002
  7. 差戻し・不足修正

    原則局担当、給与班の直接修正も可能。連絡調整は外部。

    SCR-002 / OP-E-RETURN
  8. 給与班が確定・再確定

    別の再確認待ち状態は作らない。

    SCR-002 / OP-E-CONFIRM
  9. 未払いを再計算・照合

    支払済み結果は触らず差額案件へ。計算画面配置は提案。

    FUT-JLINK / OP-PAY-CALCULATE
