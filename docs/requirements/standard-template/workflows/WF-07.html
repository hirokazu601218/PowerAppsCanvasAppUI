何を入力・確認するか

  1. 認定後に事情が変わる

    旧認定は保持。

    SCR-002
  2. 変更の種類を確認

    通勤変更／病気欠勤／受給要件喪失を分ける。

    SCR-002
  3. 変更通勤届を新たに提出

    同じ通勤タブで新届出。

    SCR-002 / OP-F-CHANGE
  4. 給与班が新認定

    旧認定と精算・追給・返納を関連付け。

    SCR-002 / OP-F-CERTIFY
  5. 必要な精算・差額を確認

    具体精算式・支給月対応は未決。

    SCR-007 / OP-RETRO-CALCULATE
  6. 該当期間を一時不支給

    病気・欠勤の不支給。認定期間終了とは異なる。

    SCR-002 / OP-F-NOPAY
  7. 局担当が喪失を届出

    受給要件を失った届出。

    SCR-002
  8. 給与班が期間終了を確定

    新たな認定終了状態は作らず終了日で管理。

    SCR-002 / OP-F-END
