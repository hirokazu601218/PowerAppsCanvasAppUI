流れと戻り・分岐

青の実線: 業務の順序。茶色: 訂正・再試行。破線: 外部システムとの受渡し等。内部画面移動、別タブ、利用者による人給への切替を混同しません。

何を入力・確認するか

  1. ホームから職員検索

    支給明細へのホーム直接導線はない。

    SCR-001 / OP-001-STAFF
  2. 条件を指定して検索

    0件は旧職員・履歴・帳票を消去。権限／通信失敗は区別。

    SCR-002 / OP-002-SEARCH
  3. 職員・タブ・履歴を選ぶ

    6タブを保持し給与簿は常時読取り専用。

    SCR-002 / OP-002-SELECT
  4. 許可項目を編集

    タブ切替で入力を保持。保存機能の全区分実測は未確認。

    SCR-002 / OP-002-EDIT
  5. 保存か移動か

    保存または未保存を伴う職員／画面／読取り切替。

    SCR-002
  6. 保存・再取得

    再取得で一致した後だけ読取りへ。失敗は入力保持。

    SCR-002 / OP-002-SAVE
  7. 変更破棄を確認

    未保存なら確認。常設破棄ボタンは置かない。

    SCR-002 / OP-002-READMODE
  8. 取消して編集続行

    現在の職員・履歴・入力を保持。

    SCR-002 / OP-002-CANCEL
  9. 破棄後に支給明細へ

    続行選択後だけ破棄。職員・対象月を渡す。

    SCR-002 / OP-002-PAYDETAIL
  10. 職員詳細へ戻る

    受け手で存在・所属を再確認。検索結果保持には現行差分あり。

    SCR-005 / OP-005-RETURN
