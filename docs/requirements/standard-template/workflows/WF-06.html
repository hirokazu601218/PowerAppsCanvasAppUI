BUSINESS FLOW / WF-06

F 通勤届の提出・差戻し・認定

局担当が入力・提出 → 給与班が審査・認定。不備は元の提出者の入力へ戻り、認定後は給与計算が情報を直接参照します。

何を入力・確認するか

  1. 局担当が自局の通勤届入力

    通常非常勤職員。調査員は対象外。本人利用は将来。

    SCR-002 / OP-F-EDIT
  2. 経路・期間・入力を検証

    経路別定期／ICが混在可。詳細検証条件は未決。

    SCR-002
  3. 通勤タブで提出

    給与班へ提出状態。

    SCR-002 / OP-F-SUBMIT
  4. 給与班が審査

    認定に必要な内容を確認。

    SCR-002
  5. 差戻し・外部で理由連絡

    原則提出者が直し、同タブで再提出。

    SCR-002 / OP-F-RETURN
  6. 給与班が認定

    認定時の自動PDF生成なし。

    SCR-002 / OP-F-CERTIFY
  7. 認定情報を直接参照

    別給与情報へ認定額を重複転記しない。

    SCR-002

OP-F-EDIT 通勤届を入力 局担当者
局担当者の自局に属する業務記録。必要な共通職員基本情報だけを併用し、他局履歴を開示しない。実効方式はPD-04。		 自局職員・旧認定 → 通勤届の入力内容 認証済みで対象レコードを識別できること。
エラーを示し成功扱いしない。復旧・再実行の詳細は未決。
OP-F-SUBMIT 通勤届を提出・再提出 局担当者
局担当者の自局に属する業務記録。必要な共通職員基本情報だけを併用し、他局履歴を開示しない。実効方式はPD-04。		 通勤届・経路・対象職員 → 提出状態 認証済みで対象レコードを識別できること。
不備を表示し認定済みとして計算に使わない。
OP-F-RETURN 通勤届を差し戻す 会計課給与班
給与班が担当業務について全対象職員を扱う。局担当者・本人にはこの操作を許可しない。実効方式はPD-04。		 提出内容 → 差戻し状態 認証済みで対象レコードを識別できること。
エラーを示し成功扱いしない。復旧・再実行の詳細は未決。
OP-F-CERTIFY 通勤手当を認定 会計課給与班
給与班が担当業務について全対象職員を扱う。局担当者・本人にはこの操作を許可しない。実効方式はPD-04。		 提出内容・経路・期間 → 認定情報・認定状態 認証済みで対象レコードを識別できること。
エラーを示し成功扱いしない。復旧・再実行の詳細は未決。
