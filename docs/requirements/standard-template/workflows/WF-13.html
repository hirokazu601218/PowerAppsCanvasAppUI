流れと戻り・分岐

何を入力・確認するか

  1. 支給回を3タブで保持

    支給回の状況／出力／取込・照合。計算版選択なし。

    FUT-JLINK / OP-JLINK-SELECT
  2. 初回は全職員を選択

    職員絞込み・対象変更可能。

    FUT-JLINK / OP-JLINK-TARGET
  3. A/Mを一括・明細指定

    職員判断。再出力でも自動Mにしない。

    FUT-JLINK / OP-JLINK-AM
  4. 人数・明細数等を出力前確認

    支給回・人数・明細数・A/M件数。

    FUT-JLINK / OP-JLINK-EXPORT
  5. Excelを人給へ渡す

    人給取込エラーはI8。取得方式未決。

    EXT-JINKYU / OP-JINKYU-PROCESS
  6. 給与簿取込・最新版照合

    最新版変更で「出力後に計算結果が変更されています」。

    FUT-JLINK / OP-JLINK-RECONCILE
  7. 差分のみ・全件を切替

    職員・期間・項目・アプリ値・給与簿値・差額。

    FUT-JLINK / OP-JLINK-FILTER
  8. 差分・未解決が残るか

    全体最新ゼロを確認。外部成功証明ではない。

    FUT-JLINK
  9. 原因画面で訂正

    勤怠はSCR-003。戻る際に支給回・職員を保持。

    SCR-002 / OP-JLINK-CORRECT
  10. 差分対応の明細を選択

    差分項目行ではなく対応出力明細。変更可能・重複出力なし。

    FUT-JLINK / OP-JLINK-REEXPORT
  11. 給与班が全体を確定

    確認ダイアログなし。表示対象だけで判定しない。

    FUT-JLINK / OP-JLINK-CONFIRM
