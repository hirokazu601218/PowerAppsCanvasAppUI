BUSINESS FLOW / WF-03

A～D 決裁後変更・採用取消

変更は旧値を保持して給与班が再確認。採用取消は候補を削除せず、履歴を残して給与計算から除外します。

何を入力・確認するか

  1. 変更・取消情報を受領

    自動受領方式は未決。採用取消は給与支給前のみ。

    SCR-002
  2. 変更か採用取消か

    確認待ち／確定のどちらも取消対象。

    SCR-002
  3. 変更前の内容を保持

    実際の変更と誤登録訂正を区別。

    SCR-002 / OP-AD-CHANGE
  4. 給与班修正値と相違か

    上流変更で給与班の値を自動上書きしない。

    SCR-002
  5. 採用値を給与班が判断

    採用値・変更前後を残す。

    SCR-002 / OP-AD-CHANGE
  6. 確認待ちへ戻し再確定

    再確定まで計算へ使用しない。未払いに影響すれば再計算。

    SCR-002 / OP-E-CONFIRM
  7. 候補を採用取消にする

    候補を削除せず履歴保持。

    SCR-002 / OP-AD-CANCEL
  8. 給与計算から除外

    採用取消に伴う既支給返納は要件外。

    SCR-002
