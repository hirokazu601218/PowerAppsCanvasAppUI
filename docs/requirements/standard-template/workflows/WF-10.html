何を入力・確認するか

  1. 有効な所属・勤務月を選択

    現行全置換と異なる、10月7日改修先の取込図。

    SCR-003 / OP-003-SELECT
  2. 入力かExcel取込か

    入力中だけ。報告済みは編集・取込不可。

    SCR-003
  3. 日数・時間・備考を編集

    改修先は職員行追加／削除可。超勤3桁・欠勤整数。

    SCR-003 / OP-003-EDIT
  4. 全件検証・処理中ロック

    同報告の編集・提出を停止し全行を検証。

    SCR-003 / OP-003-IMPORT
  5. 掲載職員行を追加更新

    手修正上書き・空欄消去・0保持・未掲載保持。

    SCR-003 / OP-003-IMPORT
  6. 反映は全て完了したか

    全件事前検証でも反映途中障害はあり得る。

    SCR-003
  7. 不完全として計算除外

    復旧方式PD-05。無条件ロールバック保証なし。

    SCR-003 / OP-003-RECOVER
  8. 保存して読取りへ

    保存失敗は入力保持。未保存の読取り切替は破棄確認。

    SCR-003 / OP-003-SAVE
  9. 勤務時間を報告

    保存済み内容を報告。

    SCR-003 / OP-003-REPORT
  10. 報告済み・編集取込不可

    給与班確認で訂正が必要なら差戻し。

    SCR-003
  11. 給与班が差し戻す

    訂正・再提出後、未払いの影響分は再計算・再照合。

    SCR-003 / OP-003-RETURN
  12. 給与計算で職員別に集計

    所属別報告から職員別集計。取込不完全は含めない。

    SCR-003
