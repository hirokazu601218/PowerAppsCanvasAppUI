BUSINESS FLOW / WF-12

給与計算から確定・支払記録

計算 → 人給 → 給与簿取込 → 最新版照合。差分は原因側へ戻し、全体最新ゼロを確認して給与班確定、その後に外部支払いと記録を分けます。

流れと戻り・分岐

青の実線: 業務の順序。茶色: 訂正・再試行。破線: 外部システムとの受渡し等。内部画面移動、別タブ、利用者による人給への切替を混同しません。

何を入力・確認するか

  1. 元データ確認・支給回選択

    対象期間と支給日を区別。計算起動の配置は提案。

    FUT-JLINK / OP-PAY-PERIOD
  2. 給与を計算・根拠保存

    確認済み条件・勤怠・認定通勤・登録控除・別率。

    FUT-JLINK / OP-PAY-CALCULATE
  3. 対象・A/M確認しExcel出力

    237列xlsx。出力前確認を行う。

    FUT-JLINK / OP-JLINK-EXPORT
  4. 人給取込・給与簿CSV出力

    外部操作。成功状態の手入力は設けない。

    EXT-JINKYU / OP-JINKYU-PROCESS
  5. 給与簿CSVを取込

    給与簿は読取り専用。失敗時は前回成功分を維持。

    FUT-JLINK / OP-JLINK-IMPORT
  6. 最新版のアプリ値と照合

    出力後変更通知。古い版は一致基準にしない。

    FUT-JLINK / OP-JLINK-RECONCILE
  7. 全体最新ゼロ・未解決なし

    未知・欠落・余分・重複を確認。表示絞込みで範囲を縮めない。

    FUT-JLINK
  8. 原因に応じ元データ訂正

    再確認／再提出後に再計算。人給原因は外部で訂正。

    SCR-002 / OP-JLINK-CORRECT
  9. ボタンで給与班確定

    確認ダイアログなし。ゼロだけで自動確定しない。

    FUT-JLINK / OP-JLINK-CONFIRM
  10. 外部で支払いを実施

    アプリが実送金する要件はない。

    アプリ外・画面未指定
  11. 支払い済みを記録

    記録UI配置は提案。元の支払済み結果は不訂正。

    FUT-JLINK / OP-PAY-PAID
  12. 最終根拠・照合履歴を保持

    中間版削除後も双方額・差額等を参照可能。保存条件PD-06。

    FUT-JLINK / OP-JLINK-HISTORY
