流れと戻り・分岐

青の実線: 業務の順序。茶色: 訂正・再試行。破線: 外部システムとの受渡し等。内部画面移動、別タブ、利用者による人給への切替を混同しません。

何を入力・確認するか

  1. 職員・通勤認定を選択

    現行通常入口は認定簿表示だけ。

    SCR-002 / OP-002-HISTORY
  2. 親職員・認定・権限確認

    ボタン活性だけで認可を代替しない。

    SCR-002
  3. 別タブHTMLを開く

    認定GUIDでHTML側が再取得。

    SCR-002 / OP-F-HTML
  4. 表示取得は正常か

    削除・不一致・権限拒否では本文なし。

    EXT-COMMUTE
  5. 理由を表示・選択へ戻る

    旧職員や別認定の本文を残さない。

    EXT-COMMUTE / OP-F-RETURN-HTML
  6. 印刷・PDFを保存

    A4横2ページ。超過は印刷停止。

    EXT-COMMUTE / OP-F-PDF
  7. 元の通勤タブへ戻る

    印刷取消でも認定データは変更しない。

    EXT-COMMUTE / OP-F-RETURN-HTML
