1 業務要件定義

1.1 業務実施手順

1.1.1 業務範囲

一部設定・要件未設定あり

非常勤職員の職員基本・勤務条件、通勤、保険・税・固定控除、勤務時間報告、期末勤勉率、給与計算、人給照合、追給・返納を対象とする。A～Dの採用前工程は給与情報への受渡しを整理する。

要件未設定：採用前の番号未発行候補と番号確定職員との統合方式。

根拠：payroll-confirmed-20261007.mdbusiness-requirements.md

1.1.2 業務フロー

記載済み

給与情報を登録・確認し、認定済み通勤と報告済み勤怠等により計算する。Excelを人給へ渡し、戻り給与簿CSVと最新版の計算結果を照合する。差分を訂正して再照合し、差分ゼロで給与班が確定、支払い済みを記録する。支払済みの誤りは別の追給・返納で扱う。

業務別フロー ↗役割・分岐・例外

根拠：payroll-confirmed-20261007.mdpayroll-interface-decisions-20261008.mdbusiness-requirements.md

1.1.3 業務の実施に必要な体制

一部設定・要件未設定あり

会計課給与班は全局の計算・確認・確定・認定を担当。局担当者は自局の勤務・申請・支給明細と必要な共通職員基本情報を扱う。業務マスタ管理者とシステム管理者は役割を分離し、兼務可能。本人機能は将来追加。

要件未設定：実効ロールの属性取得元、物理権限、運用責任者・担当人数。

根拠：payroll-confirmed-20261007.mdnon-functional-requirements.md

1.1.4 入出力情報項目及び取扱量

一部設定・要件未設定あり

職員情報Excel、勤務時間Excel、人給出力xlsx、人給給与簿CSV、通勤認定簿を扱う。人給出力は237列・見出し1行目・データ2行目・文字列形式。

要件未設定：月間件数、ピーク件数、ファイル最大量、給与簿CSVの照合キー・出力行対応。

根拠：payroll-confirmed-20261007.mdpayroll-jinkyu-interface.md
