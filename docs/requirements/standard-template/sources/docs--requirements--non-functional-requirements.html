位置づけと判定ルール

要件定義書の非機能面を、デジタル庁 DS-120 実践ガイドブック第5章に沿って整理する。分類は同章の目次にあるA～R（保守を含む）を点検する。同章本文には「17項目（A～Q）」という記述もあるが、目次のR「保守」を漏らさないためA～Rを掲載する。ガイドの分類を列挙しただけでは、各項目が承認済み要件になるわけではない。

  • 既定：引用した現行の要件・運用文書に期待結果が明記されている。対象版・条件で実測し、証跡を残した場合にだけ合否を判定する。
  • 一部既定：実行条件や期待する振る舞いはあるが、負荷、時間、責任分担などの値が未決。既定部分だけを判定し、全領域を合格としない。
  • 未決：目標値・適用範囲・判定方法等を業務側と確定するまで、任意の数値を合格基準にしない。
  • 今回対象外：現在の隔離アプリでは実施しない。将来の本番移行時に適用可否を再判断し、恒久的な非該当とはしない。

以下のNFR-*は整理用IDであり、未決の数値や運用条件にユーザーが同意したことを意味しない。実機テスト・公開版の照合・ユーザー受入は別工程。要件・設計・試験対応表には設計との接点と未試験の状態を追記する。
