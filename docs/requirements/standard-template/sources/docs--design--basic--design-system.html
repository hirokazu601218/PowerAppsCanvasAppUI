B案デザイン基準 v1.05

対象アプリ：共通（自動テスト／ハンドメイド）

Fluent 2の業務向け密度＋DADSの分かりやすい案内を採用。旧DADS資料は参考扱い。

文字

下表はCSS px相当の目標。Power Apps Sizeに一律転記しない。Classic/Modernの仕様と実際の100%表示で校正し、コントロール・設定値・スクリーンショットを記録する。以前のチャットのSize初期値は未校正候補。

用途 標準 大きな文字 太さ
画面タイトル・職員名 20 24 Semibold
セクション見出し 16 18 Semibold
表・入力・ラベル 14 16 本文Normal、ラベルSemibold
ボタン 14 16 Semibold
操作案内 16 18 Normal
更新時刻等補足 12 14 Normal

表字間0、行ボックス20程度、説明24程度。v1.11の表行は48/大文字56、入力・ボタン44、セル左右12。長文は折返しと高さ増加で対応。Boldを常用しない。

v1.11のSize初期設定は、本文10.5pt／大文字12pt、節見出し12pt／13.5pt、画面タイトル15pt／18pt。1pt=4/3 CSS pxの換算を出発点にした設定であり、OS・ブラウザーの倍率や日本語フォールバックを含む実機校正済み値ではない。現行Modern Button／Text InputのSize単位はpointsである。Microsoft Button、Microsoft Text Input

帳票は固定様式のため、画面本文の文字サイズ切替を適用しない。セル内の余白不足は文字を小さくして解決せず、行高・列幅を調整する。

状態は文字でも表示。金額右寄せ、日付yyyy/mm/dd、番号は文字列。v1.11の業務表は列対応を読み取れる1pxの薄い格子を維持する。SCR-002の新しい共通詳細表は青い項目名・白い値を左右二組に配置し、入力欄・読み取り値の区別とフォーカス状態を明示する。給与簿の月別列は独立した構造とし、青い項目名・白い値の配色を合わせる。画像Bの見出しの強さは実装で抑える。

全画面の共通余白とSCR-002のタブ

  • SCR-001～SCR-006の全画面で、Power Apps親領域を横4：56：4、縦2：26：2の比率で外余白・業務領域に分ける。比率は共通のレイアウト定義を参照し、画面ごとに別の数値を持たせない。部品内16px等の余白とは別に扱い、二重に余白を加えない。
  • SCR-002の6区分はタブ型の形状・選択背景・下線や枠・文字を合わせ、通常の操作ボタンと区別する。「給与」は「給与簿」と表示する。選択状態は色だけに頼らない。
  • 職員検索結果の選択行は氏名から職員番号、在籍状態から部署略称まで連続した選択背景を使用し、途中に白帯を残さない。左マーカーと選択状態の文字も維持する。

自動テストアプリv1.14の密度・可変配置

この節は自動テストアプリへ適用する。ハンドメイドの旧v1.11配置は変更しない。寸法はアプリ内座標のpx相当。

用途 標準 大きな文字
基本情報の1行（項目名＋値＋次行への余白） 64 72
項目名の高さ 28 32
値の高さ 24 28
値の上／下パディング 0 / 4 0 / 4
基本情報の最小列幅 220 252
  • 項目名の直下へ値を配置し、以前の値領域64pxと上余白4pxを縮小する。本文の文字サイズ・行間は縮小しない。長い文字は既存のTooltipでも確認できる。
  • 基本9項目の順序を保ち、利用可能幅から1～6列を決める。大きな文字は最小列幅も広げて列数を下げる。標準文字の1920pxウィンドウ・検索展開時は6列、1366pxでは4列を目標とする。スマートフォン全体の最適化とは区別する。
  • 固定サマリーの氏名と状態の間は8px、縦中央を揃える。状態は「在籍」等の文字を維持する。
  • 職員一覧の選択背景#DCEAFFは、2行目の所属も1行目の状態と同じ右端まで揃える。左マーカーと選択状態を併用し、色だけに依存しない。
  • 各職員の下端に#E2E8F0の1px線を設ける。区切り線は装飾で、入力枠やフォーカス表示の代替にしない。行選択ボタン・操作領域・フォーカスの仕様を保つ。
  • ヘッダーの左右余白を16pxとし、既存の本文左右16pxと揃える。本文・詳細コンテナーの寸法は変えず、二重に余白を加えない。ウィンドウ幅にかかわらず余白を保ち、キャンバス基準幅1366でも業務表示幅を維持する。

操作・検証

検索を主操作、クリア・閉じるは副操作。認定簿は「認定簿を表示」。TSVのみなら「Excel出力」と誤表示しない。 サイドバー開閉は44px以上の操作領域を取り、アイコンだけに依存せずTooltipまたは表示文字で「検索を開く／閉じる」を示す。折りたたみ時も選択職員のサマリーは右側に残す。 通常文字4.5:1を目標に実色を検証。Tab順・フォーカス・読み上げ・200%拡大を実機で確認。大きな文字切替だけでは合格にしない。 FluentのBody 1=14/20、Subtitle 2=16/22とDADS業務用Denseを参考にしたプロジェクト判断で、完全準拠の宣言ではない。
