支給明細画面

選択職員・対象月の内蔵仮例による支給内訳試算。給与班の本番計算・確定と分ける。

構造を説明する略図です。入力項目・配置の確定度は各操作に従います。

詳しい画面イメージを開く 画面内の操作をまとめて読む

画面イメージは架空データのHTMLモックです。Power Appsでの実装・アクセシビリティ・保存・認可を検証済みとは扱いません。

この画面の操作

OP-005-HOME · SCR-005

ホームへ戻る

現行実装

ログイン主体を保持してホームへ戻る。

担当: ログイン利用者
OP-005-MONTH · SCR-005

試算対象月を変更

確定改修要件

対象変更で旧結果と根拠を失効させ、新入力を確認する。未選択なら選択案内。

担当: 会計課給与班 / 局担当者
OP-005-RECALC · SCR-005

内蔵仮例を再計算

現行実装

入力版を固定して仮例の検証・試算を実行する。Dataverse保存・確定・支払を呼ばない。

担当: 会計課給与班 / 局担当者
OP-005-DETAILS · SCR-005

支給・控除内訳を開閉

確定改修要件

支給・控除を個別に開閉し、見出し金額と固定サマリーを維持する。

担当: 会計課給与班 / 局担当者
OP-005-RETURN · SCR-005

職員詳細へ戻る

現行実装

職員番号・対象月を戻し、存在・所属を再確認する。

担当: 会計課給与班 / 局担当者

境界・未決・注記

  • 現行再計算ではDataverseの保存・支給確定・支払処理を行わない。
  • 通常PCサマリー固定と狭い・低い領域の全体スクロールは承認A。引継ぎ公開38で通常到達を観測。focus見切れ・履歴AX差、正式P/H・最終照合は残る。制度式・Issue #51は未完了。
  • 改修先計算の配置をこの画面へ断定しない。レビュー上の候補配置には提案を明記。
