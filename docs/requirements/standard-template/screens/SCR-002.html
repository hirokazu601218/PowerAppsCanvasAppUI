職員マスタ検索・詳細

検索・履歴・6タブ表示の現行画面。E・F・Gの将来業務を既存タブに追加する。

構造を説明する略図です。入力項目・配置の確定度は各操作に従います。

詳しい画面イメージを開く 画面内の操作をまとめて読む

画面イメージは架空データのHTMLモックです。Power Appsでの実装・アクセシビリティ・保存・認可を検証済みとは扱いません。

この画面の操作

OP-002-SEARCH · SCR-002

職員を検索

現行実装

入力条件を確定し、認可範囲の職員を取得する。

担当: 会計課給与班 / 局担当者
OP-002-SELECT · SCR-002

職員を選択

現行実装

12桁番号と所属を再検証し、当該職員の必要データを取得する。

担当: 会計課給与班 / 局担当者
OP-002-SIDEBAR · SCR-002

検索欄を開閉

現行実装

検索欄の幅と表示を切替え、閉じた領域をTab対象から外す。

担当: 会計課給与班 / 局担当者
OP-002-TABS · SCR-002

詳細タブを切替

現行実装

取得済みデータでタブを切替える。給与簿は常時読取り専用。

担当: 会計課給与班 / 局担当者
OP-002-HISTORY · SCR-002

履歴を選択

現行実装

選択GUIDで該当職員の履歴を表示する。0件・単一件・複数件を区別する。

担当: 会計課給与班 / 局担当者
OP-002-EDIT · SCR-002

編集モードへ

現行実装

対象レコードと表示値を確認し、許可列の入力バッファを作る。

担当: 会計課給与班 / 局担当者
OP-002-SAVE · SCR-002

変更を保存

確定改修要件

変更された許可列のみ保存し、再取得した内容と一致を確認して読取りへ戻す。

担当: 会計課給与班 / 局担当者
OP-002-READMODE · SCR-002

読取りモードへ

現行実装

変更なしなら読取りへ。未保存なら破棄確認を表示する。

担当: 会計課給与班 / 局担当者
OP-002-CANCEL · SCR-002

破棄確認を取消

現行実装

保留した移動・職員変更・読取り切替を取消し、編集を続ける。

担当: 会計課給与班 / 局担当者
OP-002-DISCARD · SCR-002

破棄して続行

現行実装

明示的な続行を受けた後に入力を破棄し、保留していた目的画面／職員へ移動する。

担当: 会計課給与班 / 局担当者
OP-002-LEDGER · SCR-002

給与簿の月範囲変更

現行実装

職員と月範囲で取得し、163項目×登録済み支給行を表示。同月複数行は別列。

担当: 会計課給与班 / 局担当者
OP-002-PAYDETAIL · SCR-002

支給明細へ

現行実装

選択職員・対象月を渡し、遷移先で存在と所属を再確認。

担当: 会計課給与班 / 局担当者
OP-002-HOME · SCR-002

ホームへ戻る

現行実装

ログイン主体を保持してホームへ戻る。

確定改修要件

採用ごとの識別子で同じ候補へ12桁番号を反映する。再採用は新しい採用識別子を使う。

OP-AD-CHANGE · SCR-002

前工程変更の差異確認

確定改修要件

変更前を保持。給与班の修正値と前工程変更値が食い違えば自動上書きせず採用値を給与班が判断する。

担当: 会計課給与班
OP-AD-CANCEL · SCR-002

採用取消を反映

確定改修要件

確認待ち・確定のいずれからも採用取消へ移し、候補を保持して給与計算から除外。

担当: 会計課給与班
OP-E-PENDING · SCR-002

確認待ちで絞り込む

確定改修要件

左検索に確認待ち絞込みを追加し、右詳細で不足・不整合を表示。確定後修正で戻った候補も含める。

担当: 会計課給与班 / 局担当者
OP-E-HISTORY · SCR-002

実際の条件変更を登録

確定改修要件

実際の条件変更は月途中を含む新しい有効期間履歴として登録。発令は勤務条件へ統合し、所属既定予算を個別予算で上書き可能。

担当: 会計課給与班 / 局担当者
OP-E-CORRECT · SCR-002

誤登録を訂正

確定改修要件

原則は局担当が不足・不整合を訂正。給与班も直接訂正可能。誤登録は確定済み履歴も直接訂正でき、前後値を残して再確認へ戻す。

担当: 会計課給与班 / 局担当者
OP-E-SUBMIT · SCR-002

内容を確認待ちにする

確定改修要件

勤務条件・保険・税等の内容を給与班の確認待ちにする。局との連絡・調整はアプリ外。

担当: 会計課給与班 / 局担当者
OP-E-RETURN · SCR-002

給与情報を差し戻す

確定改修要件

必要な修正を差戻しとし、原則局担当が直して再提出する。

担当: 会計課給与班
OP-E-CONFIRM · SCR-002

給与情報を確定・再確定

確定改修要件

給与班が対象・内容を確認して確定する。訂正後も同じ確認待ちから再確定し、影響する未払い結果を再計算・再照合へ。

担当: 会計課給与班
OP-F-EDIT · SCR-002

通勤届を入力

確定改修要件

認定ヘッダーと経路ごとの明細を入力。経路ごとに定期券前払いまたはIC運賃×実通勤日数を選択し混在可能。

担当: 局担当者
OP-F-SUBMIT · SCR-002

通勤届を提出・再提出

確定改修要件

内容検証後に提出。差戻しは原則提出者が修正し、同じ通勤タブから再提出する。

担当: 局担当者
OP-F-RETURN · SCR-002

通勤届を差し戻す

確定改修要件

給与班が不備を差戻し状態にし、差戻し理由をアプリ外で提出者へ連絡する。

担当: 会計課給与班
OP-F-CERTIFY · SCR-002

通勤手当を認定

確定改修要件

給与班が認定し、計算は認定済みヘッダーと経路を直接参照する。

担当: 会計課給与班
OP-F-CHANGE · SCR-002

変更届から新認定へ

確定改修要件

変更届を新たに提出し給与班が再認定。旧認定を残し、精算・追給・返納と関連付ける。

担当: 局担当者
OP-F-NOPAY · SCR-002

一時不支給期間を確認

確定改修要件

病気・欠勤で通勤しない期間は通勤手当を支給しない。認定期間終了と区別する。

担当: 会計課給与班 / 局担当者
OP-F-END · SCR-002

認定期間の終了を確定

確定改修要件

給与班が認定期間の終了を確定する。

担当: 会計課給与班
OP-F-HTML · SCR-002

認定簿を表示

現行実装

選択認定GUIDだけを別タブHTMLへ渡し、HTML側で親職員と認定を再取得。

担当: 会計課給与班 / 局担当者
OP-G-REGISTER · SCR-002

外部決定結果を登録

確定改修要件

紙・電子で受領した外部機関の決定結果を担当局または給与班が手入力する。住民税は税固定控除、共済・保険・ハローワークは社会保険。

担当: 会計課給与班 / 局担当者
OP-G-CONFIRM · SCR-002

外部決定結果を確認確定

確定改修要件

給与班が決定内容・対象職員を確認して確定する。給与へ影響する内容はそれまで使わない。

担当: 会計課給与班
OP-002-CLEAR · SCR-002

検索条件をクリア

提案

レビュー案として検索入力・条件を初期状態へ戻す。再検索・選択解除のタイミングは未確定。

担当: 会計課給与班 / 局担当者
OP-002-FONT · SCR-002

文字サイズを切替

現行実装

ヘッダー直下の操作領域で文字サイズを切替える。

担当: 会計課給与班 / 局担当者
OP-JLINK-RETURN · SCR-002

人給連携へ戻る

確定改修要件

訂正経路から支給回・職員を保持して人給連携へ戻る。更新された元データは再確認・再計算・再照合が必要。

担当: 会計課給与班

境界・未決・注記

  • 住民税は税固定控除タブ内。外部手続きタブを新設しない。
  • 給与簿は常時読取り専用。既存56項目の読取検証は新モデルの編集・保存合格を意味しない。
  • 給与簿163項目表示と人給出力237列は別契約。
  • 勤務条件・保険等の確認状態は改修先。現行実装へ読み替えない。
