業務の内容
勤務時間報告画面

所属×勤務月の報告。現行は一覧内編集・全置換取込。確定改修要件は追加更新方式。

構造を説明する略図です。入力項目・配置の確定度は各操作に従います。

詳しい画面イメージを開く 画面内の操作をまとめて読む

画面イメージは架空データのHTMLモックです。Power Appsでの実装・アクセシビリティ・保存・認可を検証済みとは扱いません。

この画面の操作

OP-003-HOME · SCR-003

ホームへ戻る

現行実装

ログイン主体を保持してホームへ戻る。

担当: ログイン利用者
OP-003-SELECT · SCR-003

局・月・報告を選択

現行実装

有効対象月と報告を選び、有効バッチ明細をNo順・課室で表示する。

担当: 会計課給与班 / 局担当者
OP-003-EDIT · SCR-003

勤務実績を一覧編集

現行実装

同画面内に全明細のドラフトを作り日数・時間・備考を編集する。

担当: 会計課給与班 / 局担当者
OP-003-SAVE · SCR-003

勤務実績を保存

現行実装

全明細・reportId・expectedVersionを既存保存フローへ送り、成功後にヘッダー・有効明細を再取得。

担当: 会計課給与班 / 局担当者
OP-003-READMODE · SCR-003

勤怠編集を取り消す

現行実装

未保存変更があれば破棄確認。続行で破棄、取消で全ドラフトを保持。

担当: 会計課給与班 / 局担当者
OP-003-IMPORT-CURRENT · SCR-003

現行Excel全置換取込

現行実装

現行は新GUIDバッチへ全行保存し、件数・版・入力中状態確認後に有効バッチを全置換する。

担当: 会計課給与班 / 局担当者
OP-003-IMPORT · SCR-003

勤務実績を追加更新取込

確定改修要件

掲載行を追加／更新。手修正済みでもファイル優先。空欄は消去し0は0。非掲載の既存職員行を残す。

担当: 会計課給与班 / 局担当者
OP-003-RECOVER · SCR-003

取込失敗を復旧・再実行

確定改修要件

失敗情報と対象報告を確認し、不完全結果を利用せず復旧・再実行する。

担当: 会計課給与班 / 局担当者
OP-003-ROWEDIT · SCR-003

職員行を追加・削除

確定改修要件

対象報告内で職員行を追加／削除できるようにする。保存時の所属・対象職員・状態を検証する。

担当: 会計課給与班 / 局担当者
OP-003-REPORT · SCR-003

勤務時間を報告

現行実装

現行は確認モーダルから実行。報告後は編集・取込を停止する。

担当: 会計課給与班 / 局担当者
OP-003-RETURN · SCR-003

報告を差し戻す

確定改修要件

給与班が差戻し後、局担当が訂正・再提出。影響する未払い結果は再計算・再照合。

担当: 会計課給与班
OP-JLINK-RETURN-ATT · SCR-003

人給連携へ戻る

確定改修要件

勤怠訂正経路から支給回・職員を保持して戻る。保存・再提出・再計算が必要な状態を見落とさない。

担当: 会計課給与班

境界・未決・注記

  • 初期読取り専用。現行は入力中の報告を編集し、成功後に再取得。
  • 報告済みロックと差戻しを維持。実効業務認可、同時操作・途中障害は別検証。
  • 現行全置換と将来の未掲載行保持を同時に実装済みとしない。
