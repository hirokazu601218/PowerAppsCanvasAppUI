この要件が関係する操作

OP-003-SELECT · SCR-003

局・月・報告を選択

現行実装

有効対象月と報告を選び、有効バッチ明細をNo順・課室で表示する。

担当: 会計課給与班 / 局担当者
OP-003-EDIT · SCR-003

勤務実績を一覧編集

現行実装

同画面内に全明細のドラフトを作り日数・時間・備考を編集する。

担当: 会計課給与班 / 局担当者
OP-003-SAVE · SCR-003

勤務実績を保存

現行実装

全明細・reportId・expectedVersionを既存保存フローへ送り、成功後にヘッダー・有効明細を再取得。

担当: 会計課給与班 / 局担当者
OP-003-READMODE · SCR-003

勤怠編集を取り消す

現行実装

未保存変更があれば破棄確認。続行で破棄、取消で全ドラフトを保持。

担当: 会計課給与班 / 局担当者
OP-003-IMPORT-CURRENT · SCR-003

現行Excel全置換取込

現行実装

現行は新GUIDバッチへ全行保存し、件数・版・入力中状態確認後に有効バッチを全置換する。

担当: 会計課給与班 / 局担当者
OP-003-IMPORT · SCR-003

勤務実績を追加更新取込

確定改修要件

掲載行を追加／更新。手修正済みでもファイル優先。空欄は消去し0は0。非掲載の既存職員行を残す。

担当: 会計課給与班 / 局担当者
OP-003-RECOVER · SCR-003

取込失敗を復旧・再実行

確定改修要件

失敗情報と対象報告を確認し、不完全結果を利用せず復旧・再実行する。

担当: 会計課給与班 / 局担当者
OP-003-ROWEDIT · SCR-003

職員行を追加・削除

確定改修要件

対象報告内で職員行を追加／削除できるようにする。保存時の所属・対象職員・状態を検証する。

担当: 会計課給与班 / 局担当者
OP-003-REPORT · SCR-003

勤務時間を報告

現行実装

現行は確認モーダルから実行。報告後は編集・取込を停止する。

担当: 会計課給与班 / 局担当者
OP-003-RETURN · SCR-003

報告を差し戻す

確定改修要件

給与班が差戻し後、局担当が訂正・再提出。影響する未払い結果は再計算・再照合。

担当: 会計課給与班
OP-006-MONTH · SCR-006

勤務報告対象月を設定

現行実装

勤務時間報告に選択できる対象月の有効状態を保存する。

担当: 現行管理者
OP-JLINK-CORRECT-ATT · FUT-JLINK

勤怠の差分訂正へ

確定改修要件

差分原因が勤怠なら勤務時間報告へ進む。報告済みは給与班が差戻してから訂正・再提出する。

担当: 会計課給与班
OP-JLINK-RETURN-ATT · SCR-003

人給連携へ戻る

確定改修要件

勤怠訂正経路から支給回・職員を保持して戻る。保存・再提出・再計算が必要な状態を見落とさない。

担当: 会計課給与班
