OP-E-HISTORY · SCR-002

実際の条件変更を登録

確定改修要件

実際の条件変更は月途中を含む新しい有効期間履歴として登録。発令は勤務条件へ統合し、所属既定予算を個別予算で上書き可能。

担当: 会計課給与班 / 局担当者
OP-E-CORRECT · SCR-002

誤登録を訂正

確定改修要件

原則は局担当が不足・不整合を訂正。給与班も直接訂正可能。誤登録は確定済み履歴も直接訂正でき、前後値を残して再確認へ戻す。

担当: 会計課給与班 / 局担当者
OP-E-SUBMIT · SCR-002

内容を確認待ちにする

確定改修要件

勤務条件・保険・税等の内容を給与班の確認待ちにする。局との連絡・調整はアプリ外。

担当: 会計課給与班 / 局担当者
OP-E-RETURN · SCR-002

給与情報を差し戻す

確定改修要件

必要な修正を差戻しとし、原則局担当が直して再提出する。

担当: 会計課給与班
OP-E-CONFIRM · SCR-002

給与情報を確定・再確定

確定改修要件

給与班が対象・内容を確認して確定する。訂正後も同じ確認待ちから再確定し、影響する未払い結果を再計算・再照合へ。

担当: 会計課給与班
OP-G-CONFIRM · SCR-002

外部決定結果を確認確定

確定改修要件

給与班が決定内容・対象職員を確認して確定する。給与へ影響する内容はそれまで使わない。

担当: 会計課給与班
