# 要件定義書 v1.01

状態：B案の次期試作要件。現行v1.08との差分はSTATUSを参照。

## 目的・範囲

給与・会計担当が非常勤職員を検索し、基本情報と給与・通勤・保険・税の履歴を確認し、通勤手当認定簿を表示・PDF出力する。初心者の対象確認と熟練者の一覧性を両立。
当面は外部データソース不要の架空25名。Dataverse本接続、Excelインポート、自動給与計算、実務用の権限運用は試作対象外。将来接続用データ契約は設計に残す。

| ID | 要件・受入条件 |
|---|---|
| R01 | 初期化操作なしで25名と先頭職員の詳細・履歴を表示 |
| R02 | フリーワード・所属・状態をAND検索。空欄全件、山田2件、番号1件、0件を確認 |
| R03 | 20件/ページ、前後移動。選択と詳細・帳票を職員番号で連動 |
| R04 | 基本9項目・6種類の履歴・給与簿全項目を保持。詳細展開と横スクロール可 |
| R05 | 0件時に以前の職員や帳票を残さず、出力を無効化 |
| R06 | 認定簿2枚を縦モーダル表示。氏名・番号・所属連動、閉じる・拡大 |
| R07 | 認定簿を2ページPDFとして生成・保存。未接続時は説明 |
| R08 | 検索対象全件と給与簿全項目を出力。TSVコピーとXLSX出力は区別 |
| R09 | B案：左検索一覧/右詳細、Fluentの密度とDADSの案内 |
| R10 | 1366×768と1920×1080で重なり・欠けなし |
| R11 | キーボード、可視フォーカス、色以外の状態、大きな文字表示 |
| R12 | GitHubからソース・手順・試験を取得して再現可能 |

R01～R06・R09～R12をB案初回改修の優先範囲とする。R07/R08はボタンの見た目だけで完成としない。
現行認定簿は共通経路サンプルでダッシュボード通勤額と不整合。B案開発で通勤認定IDに結び付く整合データを準備し、金額を試験する。法定計算の検証とは区別する。
B案の明文化したデザインが旧HTML外観優先に優先。HTML業務項目・機能・帳票様式は維持。画像で省略した税・固定控除・給与簿も削除不可。
