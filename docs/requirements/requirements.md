# 要件定義書（現行単一アプリ）

App ID 204a48dc-7f23-43dd-b934-4654a3cfa306 の改修で使用するR15～R23を索引する。[画面要件](screen-requirements.md)は画面・操作、[非機能要件](non-functional-requirements.md)は品質条件、[要件対応表](traceability-matrix.md)は設計・試験・要件間関係の索引である。未実装・実装差分・判断待ち・未照合は[未決一覧](open-decisions.md)に集約する。

旧R01～R14、HYB、COM-DVと旧版の受入・配布方法は[移行前の要件書](../../records/docs/requirements/requirements-before-consolidation.md)に保存した。元のT_通勤のCOM-DV-001～003は現行_STUDIOテーブルの実装証拠ではない。

## 目的・適用範囲

非常勤職員の検索、基本情報・履歴・通勤認定簿・基準給与簿の確認を対象とする。SCR-005は内蔵仮例による試算であり、本番の給与計算・支払実行ではない。画面ID・画面間情報・所属制限は画面要件1～5章、詳細の優先条件は9章を参照する。相違があれば2026-09-27のSCR-002画面変更は[画面要件9.2.2・9.4](screen-requirements.md)を優先し、編集・保存の9.7・9.8は引き続き適用する。
